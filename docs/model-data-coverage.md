## 4. Как выбирать окно в ноутбуке

`START` / `END` — UTC ISO, `END` не входит в срез.

| Задача | Окно |
|--------|------|
| Сутки без дыр | любой из 6–9, 11–13, 15, **21–26** августа |
| Почти сутки, одна 5-мин дыра | 14 августа |
| Длинный сплошной кусок днём | 18 августа 06:15–18:50 |
| После дыры 19→20 | с `2026-08-20T12:20:00Z` |
| Максимум истории | 22.07–27.08, помня июльскую дыру и **19.08 17:15→20.08 12:20** |

Пример полных суток:

```text
START = "2026-08-21T00:00:00Z"
END   = "2026-08-22T00:00:00Z"
```
