# Результаты controlled B↔C — `wsfanout_bc_20260813r2`

## Итоговый вердикт

**`B=valid`; `C=valid`; причинный вердикт B↔C: полный разбор и расчёт non-XRP не доминирует в этом окне.**
Обе руки штатно завершили `probe` и свежий XRP ping с кодом `0`. Supervisor записал `supervisor_finished` в `2026-08-13T09:37:13Z`. Пороги reconnect/wave, покрытие raw+ping и `safety_abort=0` выполнены независимо для B и для C. Объединённые выборки после прогрева дают `S/P p99` около единицы, dual-минуты `>500 / >1000` равны `0 / 0` из 50. По заранее заданной матрице это `B≈C`, обе руки около ping: гипотеза «полный разбор и расчёт — главный источник хвоста» в этом автономном окне не подтверждена.

Это не опровержение H1 вообще и не производственный лимит. Путь приёма здесь общий для обеих рук: `receive_mode=immediate_drain_unbounded_app_queue`. Серия не включает bars, долговременную запись и publisher. Фон (производственный сборщик и уплотнение) записан, но не переключался. Один последовательный порядок `B → C` даёт предварительный, не повторённый вердикт.

## B↔C решение

Решение по заранее заданной матрице для этой пары: **`B≈C`, обе около ping**.

| Классификация | Статус |
|---|---|
| Полный разбор и расчёт доминирует | **не подтверждена** в этом окне: C не хуже B, тяжёлого хвоста нет |
| Fan-out соединений остаётся доминирующим | **не классифицируется этой парой одной**: для `A<B≈C` нужна валидная A той же серии; отдельно B и C тихие |
| Смешанная причина | **не подтверждена**: C не хуже B |
| H1 не воспроизведена в этом окне | **да, предварительно** |

Не доказано: производственный профиль со bars и записью; вклад фона; устойчивость во втором независимом окне.

## Следующий шаг по лестнице

P1 (валидный controlled B↔C после форензики, без ослабления порогов) **закрыт**. Повторять ту же пару с теми же knobs не нужно.

Следующий минимальный шаг — не ещё один B↔C, а проверка того, что дизайн относит к невоспроизведению H1: производственные смещения (bars, запись, совместная нагрузка) либо отдельный контролируемый фон вкл/выкл. Track (B) по-прежнему не открывается.
