# Трек сбора: готовность стать основой склейки

Трек: сбор и хранение. Дата фиксации: 2026-08-16.  
**Актуализация: 2026-08-27** — текущий production-сборщик на VPS принят как рабочая top-версия трека D (после суточного gate на retention `.state`).

**Вывод.** Задача публичного сбора данных закрыта. Зафиксированный профиль
`L1` — основа для блок-схемы трека склейки. Это не открытие реализации
склейки, не приватные каналы и не живая торговля.

Полную автономность без человека и сторожа сервера в этом треке не закрывали.
Их добирают в склейке: контур всё равно будут менять и усложнять.

Не закрыто здесь и не блокирует старт спецификации склейки:

- сторож по службе, журналу `runtime.log` и диску;
- недели без присмотра;
- задержка цикла событий и посекундные ресурсы — в полный контракт не входили.

Снято как острый долг D (2026-08-25→27): вечный рост `.state/spread_*.json` → memcg OOM уплотнителя → лаг склейки. См. retention-док.

## Что можно закладывать в блок-схему склейки

Ниже — факт измерений на этом хосте и этом профиле, не цель и не обещание
на другом конфиге.

После прогрева не короче 10 минут:

- объединённый 99-й процентиль задержки доставки OKX / Bybit ниже 100 мс;
- отношение сборщик / контрольный опрос по `XRP` не выше `2.0`;
- не больше одной минуты из 60, где обе ноги выше 500 мс; минут выше 1000 мс нет;
- внеплановых обрывов, ошибок протокола и невосстановленных сессий нет;
- плановый обрыв (часто код `1006`) — честная дыра, не провал гейта.

Не закладывать: хвост 11.08 (другой двоичный файл), удалённую копию баров как обязательную,
торговлю по подавленному тику, fill через `[t_down, t_up]` без политики fail-close.
