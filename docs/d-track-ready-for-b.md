# Трек сбора: готовность стать основой склейки

Трек: сбор и хранение. Дата фиксации: 2026-08-16.

**Вывод.** Задача публичного сбора данных закрыта. Зафиксированный профиль
`L1` — основа для блок-схемы трека склейки. Это не открытие реализации
склейки, не приватные каналы и не живая торговля.

Полную автономность без человека и сторожа сервера в этом треке не закрывали.
Их добирают в склейке: контур всё равно будут менять и усложнять.

## Что закрыто в сборе

| Задача | Вердикт | Доказательство |
|--------|---------|----------------|
| Публичный сборщик на сервере | принят как производственная основа | `app/screaner_b_o.py`, служба `spread-collector.service` |
| Тики до резервной копии | приняты | `live` → `compact` → `backup1tb:spread-compacted` |
| Бары для скринера | приняты локально на сервере | `/data/bars`; удалённая копия баров не обязательна |
| Плановый переподключение и запрет устаревшего спреда | приняты | `canary` 15–16.08, 24 ч |
| Задержка доставки на профиле `L1` | принята по быстрому отказу | два независимых окна 60 мин 16.08 |

Доказательства — `canary` около 24 ч и два окна по 60 мин, не 72-часовая выдержка.

Не закрыто здесь и не блокирует старт спецификации склейки:

- сторож по службе, журналу `runtime.log` и диску;
- защита от отпуска (нехватка памяти у уплотнителя → переполнение диска);
- недели без присмотра;
- задержка цикла событий и посекундные ресурсы — в полный контракт не входили.

## Зафиксированная версия

Это фиксированный набор параметров. Другие флаги, другой хост или другое `N` —
новый профиль и новый гейт задержки.

| Поле | Значение |
|------|----------|
| Хост | `root@38.180.94.108` |
| Вход | `app/screaner_b_o.py` |
| Набор пар | `bybit_okx_universe.csv`, строки `0…337` |
| Книги | 337× OKX `books5` + 337× Bybit `orderbook.1` |
| Бары | 337× OKX `candle5m`; Bybit `kline.5` выключен |
| Схема | `SPREAD_LEAN_SCHEMA=1`, `SPREAD_COLLECT_BARS=1` |
| Переподключение | `SPREAD_WS_RECONNECT_V2=1`, `SPREAD_WS_CONNECT_PER_SEC=3` |
| Запрет устаревшего тика | `SPREAD_TICK_SKEW_MAX_MS=2000`, `SPREAD_TICK_AGE_MAX_MS=2000` |
| Тики | первая запись `/data/live`, конечная копия `backup1tb:spread-compacted` |
| Бары | `/data/bars` на сервере |
| Фон | таймеры уплотнения и выгрузки тиков включены |
| Слияние каналов | нет |

Инвариант записи: явная дыра лучше, чем спред из устаревших ног после обрыва.

Подробные числа гейта: [`b-public-l1-gate-config.md`](b-public-l1-gate-config.md).

## Что можно закладывать в блок-схему склейки

Ниже — факт измерений на этом хосте и этом профиле, не цель и не обещание
на другом конфиге.

После прогрева не короче 10 минут:

- объединённый 99-й процентиль задержки доставки OKX / Bybit ниже 100 мс;
- отношение сборщик / контрольный опрос по `XRP` не выше `2.0`;
- не больше одной минуты из 60, где обе ноги выше 500 мс; минут выше 1000 мс нет;
- внеплановых обрывов, ошибок протокола и невосстановленных сессий нет;
- плановый обрыв (часто код `1006`) — честная дыра, не провал гейта.

Не закладывать: хвост 11.08 (другой двоичный файл), удалённую копию баров,
торговлю по подавленному тику.
