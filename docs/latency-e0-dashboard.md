## 3. Дизайн E0

### Что делаем

Склеить минуты двойного пика (>1000 мс, обе ноги скринера) с ближайшим снимком `heartbeat` (`buffer_size`, `queue_depth`, `last_write_latency_ms`) и фактом `backpressure_hit` в той же минуте.

**Факт / артефакт:** `output/latency_screener_vs_ping_dual_spike.csv` — **сводка** (порог → число минут), не список минут. Список из 42 минут восстанавливают из меток lean / ячеек [`research/latency_screener_vs_ping.ipynb`](../research/latency_screener_vs_ping.ipynb) за то же окно (как в результате 2026-08-05).

### Кто

| Роль | Действие |
|------|----------|
| Validation Agent | прогон, таблица, вердикт по порогам ниже |
| Review Critic | сила вывода; запрет «сброс буфера — причина» без E5 |
| Text Stylist | только этот документ |
| Runtime Storage / Schema Contract | не нужны для E0 |

### Не делать

Останавливать боевой коллектор; теневой процесс; правка кода; обрезка журналов; писать в `/data/live`; трогать уплотнение / резервное копирование.

### Команды (только чтение, VPS + локальные CSV)

```bash
# 0) Контекст
hostname; date -u
test -f /var/log/spread/runtime.log && wc -l /var/log/spread/runtime.log
ls -la /var/log/spread/runtime.log* 2>/dev/null | head

# 1) Heartbeat / backpressure за окно UTC 13:00–19:00 2026-08-05
# При ротации — подставить нужный runtime.log.* (только чтение).
grep -E 'heartbeat |backpressure_hit ' /var/log/spread/runtime.log \
  | awk '/2026-08-05T1[3-8]:|2026-08-05T19:0/' \
  > /tmp/e0_heartbeat_overlap.txt
wc -l /tmp/e0_heartbeat_overlap.txt
grep -c 'backpressure_hit' /tmp/e0_heartbeat_overlap.txt || true
```

Далее локально (или на VPS после копирования): список минут двойного пика (колонка минуты UTC) × ближайший `heartbeat` ±30–45 с → таблица `minute | buffer_size | queue_depth | last_write_latency_ms | backpressure_hit`.

Ожидаемый разбор строки `heartbeat` (фрагмент):

```text
heartbeat | ... | buffer_size=<n> | ... | queue_depth=<n> | ... | last_write_latency_ms=<float|None> | ...
backpressure_hit | policy=retain_raw_in_buffer | rows=... | queue_depth=...
```

## 4. Светофор (критерии)

| Исход | Порог | Следствие |
|-------|-------|-----------|
| **H4 отвергнута** | ≥70% минут с двойным пиком >1 с при `buffer_size=0` и `queue_depth=0` и без `backpressure_hit`; n≥30 из ~42 | основная причина редких хвостов — не путь публикации; дальше один шаг из лестницы: E2 теневой N=1 (отдельное согласование) |
| **H4 жива** | ≥70% минут с `buffer_size>0` или `queue_depth>0` или `backpressure_hit` | H4 остаётся в игре → E5/E3 на теневом контуре, не правка приёма |
| **Измерение провалено** | <30 минут, пригодных к склейке, или нет `heartbeat` за окно | сначала поиск ротированного журнала; не правка кода |
| **Запрет вывода** | совпадение по времени сброса буфера ↔ пик | не равно «сброс буфера — причина» без E5 |

E0 сам `gate #1` не закрывает: сужает слой **публикация vs цикл событий**.
