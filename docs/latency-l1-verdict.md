# `L1` — итоговый вердикт

Трек: сбор, задержки. Профиль зафиксирован 2026-08-16.
Не открывает реализацию склейки.

## Вердикт

**Профиль `L1` принят по быстрому отказу двух независимых окон по 60 минут.**

Полный [контракт приёмки](latency-production-acceptance-contract.md) **не закрыт**:
задержка цикла событий и посекундные процессор / память / дескрипторы не писались.
По лестнице профилей задержки, которую утвердили до запуска, этого достаточно:
отказ после первого проваленного окна; приёмка после второго независимого.

Ступени `L2` / `L3` / `L4` не нужны, чтобы найти рабочий конфиг сбора с 99-м
процентилем ниже 100 мс.

Сводка готовности трека: [`d-track-ready-for-b.md`](d-track-ready-for-b.md).
Числа для блок-схемы: [`b-public-l1-gate-config.md`](b-public-l1-gate-config.md).
