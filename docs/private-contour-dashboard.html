Private / Live Contour — шпаргалка

Для человека, который понимает код на уровне else/bybit_ws.py: public listeners, private WS с cmd_queue → sender → ws.send, trade_manager. Ниже — куда переехали те же роли в новом контуре (app/bot/**), без дампа каждого private-метода.

public L1 private warm signal / policy prepare send / dual-leg journal / safety Warm-Lat gap: live_broker
Навигация
Карта bybit_ws → new Поток 1. Старт 2. Public L1 3. Warm session 4. Сигнал 5. Prepare 6. Send 7. Journal 8. Warm-Lat 9. Gap live_broker

Сравнительная таблица: bybit_ws.py → новый модуль

Эталон скорости: JSON → queue.put → long-lived sender → ws.send. Новый стек обязан быть корректнее (approval/lease/journal), но на send — не медленнее этой формы.

Поток сигнала → place (после warm)

Public L1 → Policy / gear2 → Hot prepare → Queue / dispatch → Warm trade WS → Journal ack/fill

В старом мире всё после L1 жило в одном trade_manager. Сейчас: policy решает что, prepare делает durable work, send — почти только network.

В bybit_ws это было… эталон скорости Path A (без замеров стадий). Warm-Lat как раз сравнивает «старую форму» с текущим prepare на тёплой сессии.
