## 4. Связь с хвостом на днях

Факт: p50 везде ~31 / 19 мс. p99 растёт, когда в слоте или часе больше строк (21:40; 17-е 13–15 ч с 5,9–6,7 млн).

Допущение (задержка цикла не писалась): очередь одного `asyncio`-цикла при N=337 и пачке сообщений. Это согласуется со старым сравнением скринер vs `ping` на тихом `ping`. Не доказано как единственная причина.

Не объясняет хвост: смена флагов относительно `L1`; обрыв сокета как замедление оставшихся тиков (см. [дыры и задержки](holes-latency-20260820.md)).

Теневые контуры (E2, доза `N`, раздача каналов) **нельзя** подставлять вместо этого сравнения: у них другой `N`, бары выключены, другой сброс и другие пути.
