# Публичные ставки финансирования Bybit и OKX

Скачано 2026-10-22, только чтение публичных API. Повторный запуск `python3 research/gear23_funding/download_market_funding.py` не качает заново серии, у которых кэш уже полный для этого окна.

Окно запроса: с 2026-04-01 00:00 UTC включительно до 2026-10-23 00:00 UTC не включая. Вселенная: 450 монет, у которых сейчас есть linear USDT-perpetual и на Bybit (status Trading), и на OKX (instId `BASE-USDT-SWAP`, state live). Монеты только одной биржи в файлы не входили.

Глубина ответа биржи короче запрошенного окна. У Bybit 262 серии начинаются 2026-04-01, остальные позже (монета ещё не торговалась). У OKX публичная история почти у всех начинается 2026-07-20. Пять OKX-серий пустые: AMGN, GE, NVO, PANW, VST. Ошибок загрузки нет.

Знак: положительная ставка — лонг платит, шорт получает. Это ставка за одно начисление, не годовая.

## Единицы

- `funding_rate`, `settled_rate` — доля за начисление. `0.0001` = 0.01% за интервал.
- `rate_pct` = доля × 100. Та же шкала, что процент спреда: `0.01` значит 0.01%, `−2` значит −2% за это начисление.
- `interval_hours` — часы от предыдущего начисления той же серии. У первой точки серии пусто.
- `rate_per_8h_pct` — `rate_pct`, умноженный на `8 / interval_hours`, если зазор не меньше 0.5 часа. Так 1-часовая и 8-часовая печать сравнимы. У первой точки пусто.

`settled_rate` берётся из `realizedRate`, если биржа его отдала, иначе из `fundingRate`.

## Файлы

`settlements.csv` — одно начисление, одна строка. 490860 строк. Колонки: exchange, base_coin, symbol, ts_ms, ts_utc, hour_utc, funding_rate, realized_rate, settled_rate, rate_pct, interval_hours, rate_per_8h_pct.

`by_coin.csv` — одна строка на монету и час, если хотя бы одна биржа начислила в этот час. 330706 строк, из них 160154 с обеими биржами (`both=1`). `rate_diff_pct` = Bybit − OKX в процентах за начисление. `rate_per_8h_diff_pct` — то же после приведения к 8 часам; пусто, если у одной из сторон нет интервала.

`by_exchange.csv` — час и биржа. `n_coins` — сколько монет начислились в этот час. `mean_rate_pct` и `median_rate_pct` — сечение по `rate_pct`, то есть по ставке за начисление. В одном часе рядом стоят 4-часовые и 8-часовые монеты; для сравнения режима удобнее `rate_per_8h_pct` из двух других файлов.

`coverage.csv` — по серии: число точек, первая и последняя метка, медианный интервал, текущий интервал Bybit в часах.

`universe_joint.csv` — список 450 монет и символы. `cache/` — сырые ряды по монете. `meta.json` — счётчики. `errors.csv` — пустой.

Спред и собственные сделки в эти файлы не присоединены.
